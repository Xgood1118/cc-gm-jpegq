# DCT 量化往返

纯标准库实现的 JPEG 量化往返：RGB → YCbCr 4:2:0 → 8x8 分块 DCT → 量化 →
反量化 → 反 DCT → 重建 RGB 写回 PNG。

## 实现要点

- **变换**：`dct_8x8` / `idct_8x8` 带正交归一系数 `1/4 * C(u) * C(v)`
  （`C(0)=1/√2`，其余为 1），正反变换成对，往返无整体亮度偏移；
  常数块往返误差为 0（测试阈值 1e-9）。
- **量化**：`LUMA_Q` / `CHROMA_Q` 按 zigzag 扫描顺序存放（低频在前），
  量化时经 `ZIGZAG` 表映射回自然 (u, v) 频率位置。高频项除以大步长被压掉，
  低频保留。`scale` 线性放大量化步长。
- **色彩**：`rgb_to_ycbcr` 输出全分辨率 Y 平面（-128 电平偏移）和
  半分辨率 Cb/Cr 平面（2x2 盒式均值，4:2:0）。写回时色度最近邻上采样，
  三个通道全部重建。
- **边界**：宽高不是 8 的倍数时，边界块用**镜像（对称反射）填充**——
  块外坐标 `i` 反射为 `-i` 或 `2n-2-i`，而不是钳制重复边缘像素，
  避免右下角出现拉伸痕迹。写回时只取原图范围内的像素，往返后尺寸不变。

## 运行

```
python gen_samples.py
python -m jpegq.cli data/photo.png --scale 1.0 --out roundtrip.png
python -m pytest tests -q
```

`photo.png` 96x64，左半是双通道渐变，右半是两像素宽的高频条纹，
用来检验量化对高频的影响。

## 实测结果（data/photo.png）

| scale | PSNR | 渐变区平均误差 | 条纹区平均误差 |
|-------|--------|----------|----------|
| 1.0 | 31.65 dB | 1.90 | 6.40 |
| 3.0 | 22.34 dB | 5.22 | 17.17 |

（平均误差为区域内每像素三通道绝对误差的均值。）

scale=1.0 时 PSNR 超过 30 dB；scale 增大，量化步长变粗，PSNR 随之下降。
条纹区是高频内容，量化误差明显大于平滑的渐变区，符合预期。

## 测试

`python -m pytest tests -q` 覆盖：常数块无损往返（1e-9）、任意块 DCT/IDCT
往返无偏移、zigzag 与量化表的对应关系、色度 4:2:0 分辨率（含奇数尺寸）、
边界块尺寸保持与无拉伸、PSNR 阈值与随 scale 单调下降。
